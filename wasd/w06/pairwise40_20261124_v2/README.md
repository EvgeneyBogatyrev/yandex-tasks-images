# Comparative image display assets

Cropped derivatives for a perceptual image study. Native256SR panels and nativeLR64 enlarged4x with nearest-neighbor, with the same outlined region and dimmed surroundings. Some explicitlyconstructed teaching variants contain an artificial local grid.

Original photographs are credited individually in ATTRIBUTION.csv and PNG metadata, under the linked CC BY2.0 licenses. Changes are described there. Original authors do not endorse the study.

Only display PNGs and publiccredit/file-integrity metadata are included. No study answers, participant information, private masks, model weights or credentials are published.
